# 评论功能配置指南（Waline）

博客本身是纯静态站，评论数据需要一个后端来存储和提供接口。这里使用 **Waline**。
本博客当前实际使用 **腾讯云 CloudBase（CLI 部署）**；也可选 Render + MongoDB Atlas、
Vercel 等方案（见下文）。评论和阅读量共用同一个 Waline 后端。

评论规则已经按你的要求配好：**游客只需填昵称即可评论**（不用注册邮箱），第一个注册的管理员账号可以在后台删除、审核评论。

> 说明：Zeabur 的免费共享集群已停止对新项目开放；Netlify 官方模板与 2026 年平台改动不兼容（实测函数可运行但所有路由 404），均不再推荐。

---

## 一、方案 A：Render + MongoDB Atlas（推荐，约 15 分钟）

两个平台都用 GitHub 登录、**不需要信用卡、不需要实名**。MongoDB Atlas 的 M0 免费集群永久免费，Render 免费额度每月 750 小时。
缺点：免费服务闲置 15 分钟后休眠，下次访问会有几秒到几十秒的冷启动；国内访问速度一般（区域选新加坡可改善）。

**数据库（如果你已经建好 Atlas 集群，直接从第 3 步开始）：**

1. 注册 [MongoDB Atlas](https://www.mongodb.com/cloud/atlas)，用 GitHub 登录，创建 **M0 免费集群**（区域选新加坡或香港）。
2. 点 **Connect** 复制连接串，末尾 `/` 后加数据库名：`mongodb+srv://用户:密码@cluster0.xxxxx.mongodb.net/waline`。

**部署服务：**

3. 注册 [Render](https://dashboard.render.com)，用 GitHub 登录（无需信用卡）。
4. **New → Web Service**，来源选 **Docker（Public Image）**，镜像填 `lizheming/waline:latest`。
5. Region 选 **Singapore**（离国内较近）。
6. 在 **Environment** 里添加：
   - `MONGO_URI` = 第 2 步的连接串（带 `/waline`）
   - `SECURE_DOMAINS` = `upxianyu.cn,upxianyu.github.io,xxx.onrender.com`
   - `SITE_NAME` = `咸鱼的小站`
   - `SITE_URL` = `https://upxianyu.github.io/XianyuBlogSpace-Project/`
7. 点击创建，等待构建完成（约 3-5 分钟），分配到的 `https://xxx.onrender.com` 就是评论服务端地址。
8. 打开 `https://xxx.onrender.com/ui/register` 注册管理员（第一个注册的账号自动成为管理员）。

以后升级 Waline：Render 服务设置里把镜像 tag 从 `latest` 换成新版本号再重新部署，或直接在服务页面 Redeploy 拉取最新镜像。

## 二、方案 B：腾讯云开发 CloudBase 部署

国内访问快、Waline 官方支持一键部署。**注意：免费体验版（0 元/月）存在功能限制，一键部署应用时无法绑定环境（会提示"当前地域无环境/无法勾选"），需要个人版（19.9 元/月）才能正常部署**；如果坚持用 CloudBase，建议直接开通个人版后再走官方一键部署。

需要：腾讯云账号 + **个人实名认证**。

1. 打开 Waline 官方 CloudBase 部署文档：<https://waline.js.org/guide/deploy/cloudbase.html>
2. 点击文档里的 **一键部署** 按钮（直达链接）：
   <https://console.cloud.tencent.com/tcb/env/index?action=CreateAndDeployCloudBaseProject&appUrl=https%3A%2F%2Fgithub.com%2Fwalinejs%2Ftcb-starter&branch=master&appName=waline>
3. 用微信/QQ 扫码登录腾讯云，按提示完成实名认证。
4. 环境套餐选**个人版**（19.9 元/月，含 4 万资源点；有新人免费试用可以先体验）。
5. 应用配置直接下一步 → 完成，等待提示“构建中，预计 3-5 分钟”。
6. 构建完成后条目右侧会出现 **访问** 按钮，点开的网址就是评论服务端地址，形如 `https://xxx.ap-shanghai.app.tcloudbase.com`。
7. 打开 `<服务端地址>/ui/register` 注册管理员（第一个注册的账号自动成为管理员）。

**CLI 部署（推荐，已实测可用）**：网页一键部署向导对部分环境会卡在"当前地域无环境"，改用 CLI 直接指定环境 ID 即可绕开：

```bash
npm i -g @cloudbase/cli        # 安装 CLI（当前 3.7.0）
tcb login                       # 浏览器扫码登录
git clone https://github.com/walinejs/tcb-starter
cd tcb-starter
```

在 `cloudbaserc.json` 里把 `envId` 换成你的环境 ID，`runtime` 改为 `Nodejs20.19`；然后在项目里手动构建函数目录（入口 `index.js` 用官方 `__launcher.js` 逻辑，`app.js` 保持不变），装好依赖后执行：

```bash
tcb fn deploy waline -e <环境ID> --path /waline --runtime Nodejs20.19 --dir ./fn/waline --force
tcb config update fn waline --timeout 30
```

部署成功后会得到形如 `https://<环境ID>.service.tcloudbase.com/waline` 的访问地址（真实请求会自动剥离 `/waline` 前缀，Waline 路由无需改动）。本博客当前就是用此方式部署的。

**安全配置**：CloudBase 控制台 → **云函数** → waline 函数 → **函数配置 → 环境变量**里添加 `SECURE_DOMAINS=upxianyu.cn,upxianyu.github.io,你的评论域名`（改完需重新部署/重启函数生效）。

## 三、方案 C：Vercel 部署（备选）

如果 Vercel 的“账户恢复”验证能过，这条路最省事（官方推荐 Vercel + Neon）。卡在验证时先试：**换网络**（手机热点、切换代理节点）、换浏览器无痕模式、或改用**邮箱 + 一次性验证码**登录；还不行再走 <https://vercel.com/accountrecovery>。

需要：一个 GitHub 账号（已有），一个 Vercel 账号（可以用 GitHub 登录），Neon 会自动创建账号。

1. 打开官方部署文档：<https://waline.js.org/guide/deploy/vercel.html>
2. 点击文档里的 **Deploy on Vercel** 按钮，用 GitHub 账号登录 Vercel，输入一个项目名（比如 `xianyu-waline`），点击 Create。
3. 等一两分钟部署完成（会有烟花庆祝），点 **Go to Dashboard** 进入项目。
4. **创建数据库**：顶部菜单进入 **Storage** → **Create Database** → 数据库服务选 **Neon** → 点击 **Continue** → 在 Neon 登录页选 **Accept and Create**（会自动注册 Neon 账号）→ 套餐和地区直接 Continue → 数据库名不用改，Continue。
5. **建表**：在 Storage 列表里点进刚创建的数据库 → **Open in Neon** 跳转到 Neon → 左侧选 **SQL Editor** → 把 Waline 官方仓库里的 [waline.pgsql](https://github.com/walinejs/waline/blob/main/packages/server/assets/waline.pgsql) 内容整段粘贴进去 → 点击 **Run**，等待提示建表成功。
6. **重新部署**：回到 Vercel → 顶部 **Deployments** → 在最新一次部署右侧点 **Redeploy**（让数据库环境变量生效）→ 等 STATUS 变成 **Ready** → 点 **Visit**。

访问到的地址就是你的评论服务端地址，形如：

```text
https://xianyu-waline.vercel.app
```

## 四、方案 D：Netlify（暂不适用）

2026 年 Netlify 平台改动后，Waline 官方模板（netlify-starter）的路由适配已失效：函数本身能运行（探针返回正常），
但所有 `/api` 与 `/ui` 路由都返回 404。已尝试手动剥离函数前缀、serverless-http `basePath` 等修复方式均无效，
根因在 Waline 官方服务端与 Netlify 新事件格式不兼容，需等官方适配。**暂不建议在 Netlify 上部署 Waline**。

## 五、安全与防滥用配置（通用，强烈建议做）

在托管平台对应服务/函数的环境变量里添加以下配置（CloudBase 在云函数配置里，Vercel/Render 在项目 Environment 里；改完需重新部署或重启函数才生效）：

| 变量名 | 示例值 | 作用 |
|---|---|---|
| `SECURE_DOMAINS` | `upxianyu.cn,upxianyu.github.io,你的评论服务域名` | 只允许你的博客域名和评论服务域名调用接口，防止别人盗用你的服务刷评论 |
| `COMMENT_AUDIT` | `true` | 开启评论审核，新评论先进入待审核，你在后台通过后才显示（可选） |
| `SITE_NAME` | `咸鱼的小站` | 管理后台显示的名称 |
| `SITE_URL` | `https://upxianyu.github.io/XianyuBlogSpace-Project/` | 你的博客地址 |

注意：`SECURE_DOMAINS` 需要**同时写博客域名和评论服务域名**，不要带 `https://`。

## 六、把地址填进博客

1. 编辑 [config/site.json](../config/site.json)，填写：

```json
{
  "walineServer": "https://xxx.onrender.com"
}
```

2. （可选）如果你在的网络访问 unpkg 不稳定，可以加一行切换成国内常用的 CDN：

```json
{
  "walineCdn": "https://cdn.jsdelivr.net/npm/@waline/client@v3/dist"
}
```

3. 本地验证：

```bash
node build.js --examples
node server.js
```

打开任意一篇帖子，应该能看到评论框。

4. 推送上线（GitHub Actions 会自动重新构建）：

```bash
git add .
git commit -m "feat: 配置 Waline 评论服务"
git push
```

## 七、管理员注册与删评论

- **注册管理员**：打开 `<服务端地址>/ui/register`，**第一个注册的账号会自动成为管理员**，请用真实邮箱并记好密码。
- **管理评论**：打开 `<服务端地址>/ui` 登录，可以删除、编辑、置顶评论，也可以开关评论审核。
- **游客评论**：帖子底部直接填昵称和内容就能发，无需注册。

## 八、常见问题

- **评论框没显示**：按 F12 打开浏览器控制台看报错；确认 `walineServer` 已填写、代码已重新构建并推送、服务端地址末尾没有多余的斜杠。
- **评论组件加载失败（国内网络）**：把 `walineCdn` 改成 jsdelivr 那条，重新构建推送。
- **改了环境变量不生效**：环境变量改动后必须重新部署（Vercel Redeploy / Render Redeploy / CloudBase 重启函数）。
- **免费服务休眠**：Render 免费服务闲置 15 分钟会休眠，第一条评论或首次访问会有冷启动延迟，属正常现象。
- **想暂时关掉评论**：把 `walineServer` 清空，重新构建推送，页面会显示"评论功能尚未配置"的占位提示。
